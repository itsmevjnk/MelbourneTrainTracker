Brightness configuration

In this mode, the display brightness will remain constant throughout the day. The brightness can be changed on-the-fly through the web interface in normal operation mode, as well as through API calls.
In this mode, the display will change to dim gradually from sunset to midnight, and then brighten gradually until sunrise. Any on-the-fly change to the brightness through web interface or API call will put the board into manual mode until the next reset.
All times are in Melbourne (AEST/AEDT) timezone. Sunrise times set to occur before sunset time will be interpreted as occurring the day after sunset.

Sunrise and sunset times are provided by Sunrise-Sunset.
